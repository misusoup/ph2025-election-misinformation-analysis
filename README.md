# ph2025-election-misinformation-analysis
Repository for the thesis **A Comparative and Clustering-Based Analysis of Misinformation Diffusion on Facebook and X Across the 2025 Philippine Midterm Elections**. Provides the complete analytical workflow, from data integration and preprocessing to network analysis, clustering, validation, visualization, and dashboard preparation.

The study investigates how verified misinformation propagated across Facebook and X during the 2025 Philippine Midterm Elections. By reconstructing misinformation diffusion networks from viral posts and their reshare cascades, the research examines amplification behavior, compares diffusion patterns across platforms, and identifies distinct diffusion structures through hierarchical clustering.

# Repository Contents

## Dataset

The **Dataset** directory contains all datasets collected and generated throughout the study.

| Folder | Description |
|---------|-------------|
| **1. Misinformation Cases** | Contains the verified misinformation cases collected from fact-checking organizations that served as the basis for selecting misinformation incidents included in the study. |
| **2. Viral Posts** | Contains the original Facebook and X posts corresponding to each verified misinformation case. These posts served as the root posts for reconstructing misinformation diffusion networks. |
| **3. Reshare Collection** | Contains the manually collected Facebook and X reshare datasets organized into the `fb` and `x` folders. Each file contains the collected post URLs, identifiers, and parent-child relationships used to reconstruct misinformation diffusion cascades. |
| **4. Apify** | Contains the metadata scraped using Apify for Facebook and X. Each platform directory includes both the original scraped metadata and the merged datasets generated after integrating the scraped metadata with the corresponding reshare collection files. |
| **5. Final Dataset** | Contains the consolidated dataset generated after integrating all misinformation cases across Facebook and X. This dataset serves as the primary input for the analytical processes and dashboard. |

---

## Notebooks

| Notebook | Description |
|----------|-------------|
| **01_Data_Merging.ipynb** | Merges the manually collected reshare datasets with their corresponding scraped metadata, consolidates all misinformation cases into a unified dataset, and performs the preprocessing required before analysis. |
| **02_Analytical_Processes.ipynb** | Performs network graph construction, amplification metric computation, cross-platform diffusion analysis, hierarchical clustering, cluster validation, visualization, and error analysis. |

---

## Dashboard

The **Dashboard** directory contains the Power BI dashboard together with the automated pipeline used to synchronize and prepare the dashboard dataset.

| Item | Description |
|------|-------------|
| **Dashboard.pbix** | Interactive Power BI dashboard for exploring misinformation diffusion networks, amplification metrics, cross-platform analysis, clustering results, and other analytical outputs generated by the study. |
| **Pipeline Input and Output Spreadsheet/** | Contains the Excel workbook used as the primary data source for the Power BI dashboard. |
| └── **Dashboard_Data.xlsx** | Contains multiple worksheets that store both the raw extracted data from the connected Google Spreadsheet and the processed datasets consumed by the dashboard visualizations. |
| **Pipeline/** | Contains the automated dashboard data pipeline. |
| ├── **pipeline.py** | Retrieves data from the connected Google Spreadsheet, performs the required preprocessing and transformations, and updates the dashboard workbook used by Power BI. |
| └── **workflow/pipeline.yml** | Workflow configuration that automates the execution of the dashboard pipeline, ensuring the dashboard dataset remains synchronized with the connected Google Spreadsheet. |

# Data Privacy

The datasets included in this repository were collected from publicly accessible Facebook and X posts associated with verified misinformation cases. To discourage direct navigation to the original posts while preserving the integrity and reproducibility of the analytical workflow, all URLs have been replaced with the placeholder `[REDACTED]` throughout the repository.

No additional anonymization, hashing, or modification of the remaining dataset fields was performed, as the study relies on the original metadata and diffusion relationships for network reconstruction, amplification analysis, and clustering.
